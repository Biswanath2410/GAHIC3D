# GAHIC3D

3D chromosome reconstruction from sparse Hi-C. GAHIC3D fits a distance-dependent Poisson model to all pairs of loci,
including pairs with zero contacts, and optimizes it with a genetic algorithm combined with L-BFGS-B.

## Installation

```bash
conda env create -f environment.yml
conda activate gahic3d
```

## Usage

```bash
python GAHIC3D.py contact_matrix.txt out/prefix
```

The input is an n x n contact matrix (whitespace separated). The structure is written to `out/prefix_struct.txt`
(`bin x y z`). Run `python GAHIC3D.py -h` for options.

## Reproducing the paper

Tested on Ubuntu 24.04.

```bash
bash install_linux.sh        # R, Octave, Java, Python environment and the competing methods
bash run_all.sh 8            # 8 = number of cores
```

`run_all.sh` downloads the GEO data (GSE80280), runs all analyses and writes the tables to `results/tables/` and the
figures to `figures/`. It takes about 30 CPU-hours.

Chromosome3D needs CNS 1.3, which is free for academic use but cannot be redistributed. See `tools/README.md`.

## Data

- `data/groundtruth/`: ground-truth structures (8 cells; chr1, 9, 19, X; 1 Mb and 400 kb)
- `data/simulated/alpha2.0_cov0.1/`: simulated matrices at 10% depth (the other depths are generated by `run_all.sh`)
- `data/real/download_gse80280.sh`: downloads the experimental data from GEO
